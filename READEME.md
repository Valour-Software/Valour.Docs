# Valour.Docs 
### How To Run After Cloning
- Install/verify you have Node.js version 18 or higher
    - This can be done with install-node.sh on Linux
        - `sudo chmod +x install-node.sh`
        - `./install-node.sh`
- Run `npm run start` from inside the valour-docs directory
    - This can also be done from the project's Root directory with run-docs.sh
        - `sudo chmod +x run-docs.sh` on Linux
        - `./run-docs.sh`
